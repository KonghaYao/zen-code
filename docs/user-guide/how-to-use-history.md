# 如何使用历史记录

> 1. `/h` 打开历史面板
> 2. 选择会话
> 3. 按 Enter 恢复会话

## 历史记录怎么工作

历史记录按项目隔离，每个项目的会话是独立的。

数据存在 `~/.zen-code/session.db`，Zen Code 会自动管理，你不需要改它。

## 查看历史记录

输入 `/h` 打开历史面板。

列表显示当前项目的会话，每个带会话 ID 和更新时间。

## 回到某个会话

上下键选中，按 `Enter`。

切换到那个会话后，AI 之前聊过的内容都在。

## 搜索会话

按 `/` 开始搜索。输入关键词过滤列表。

## 跨项目查看

历史面板只显示当前项目的会话。想看其他项目，先切换到那个目录再打开 `/h`。

## 什么时候用历史

历史是用来找回上下文的。比如昨天聊过某个功能想继续，或者要找 AI 之前给的代码方案。

但重要的配置、代码片段还是存到文件或项目文档里更好。历史适合"找回"，不适合"存档"。
