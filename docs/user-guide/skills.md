# 技能系统

> 访问 https://skills.sh/ 搜索需要的技能按说明安装 `#技能名` 快速唤出 或 右键应用创建技能用 skills 工具 + plan 模式

## 技能是什么

技能像是给 AI 装的"专业知识包"。

比如你想让 AI 按照某个框架的最佳实践来回答，或者让它熟悉特定工具的使用方法，就可以安装对应的技能。

## AI 自动判断该用哪个技能

不需要手动告诉 AI 用哪个技能。

AI 知道有哪些技能可用，每个技能是干什么的。当你提问题时，它会自动判断该用哪个。

当然，你也可以明确指定：

```
用 brainstorming 技能帮我设计一个功能
```

## 快速唤出技能

输入 `#` + 技能名可以快速唤出技能：

```
#brainstorming
```

右键可以快速应用技能到当前对话。

## 技能存在哪里

| 位置     | 路径                     | 用途           |
| -------- | ------------------------ | -------------- |
| 项目技能 | `./.claude/skills/`      | 这个项目专用的 |
| 用户技能 | `~/.claude/code/skills/` | 你个人的技能库 |

项目技能优先级更高，会覆盖同名的用户技能。

## 如何获取技能

推荐使用 https://skills.sh/ 来安装和查询技能，不用自己写。

打开 https://skills.sh/ 搜索你需要的技能，按说明安装即可。

## 创建自己的技能

使用 skills 工具搭配 plan 模式来编写，而不是手写文件。

打开 https://skills.sh/ 进入 plan 模式，按照提示描述你想要的技能，它会帮你生成完整的技能文件。
