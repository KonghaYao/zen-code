# 快速开始

## 你第一次打开 Zen Code

想象一下：你刚clone了一个新项目，想快速了解它的结构。或者你正在写代码，卡在一个复杂的函数上。与其一个人闷头苦想，不如找个帮手。

打开终端，输入：

```bash
pnpx zen-code
```

## 第一次启动会发生什么

如果你是第一次用，Zen Code 会弹出配置向导。它想知道：

1. 你想用哪家的大模型？OpenAI 还是 Anthropic？
2. 你的 API Key 是什么？（放心，只存在你自己的电脑上）

填完这些，你就可以开始了。

## 开始聊天

界面很简单：下面是输入框，上面是对话历史。直接打字，按回车发送。

```
帮我看看这个项目是做什么的
```

AI 会读取你当前目录的文件，然后给你一个概述。

## 用命令快速切换

输入 `/` 开头的内容是命令。比如：

- `/model` - 换个模型
- `/history` - 看看之前聊过什么
- `/clear` - 清空当前对话，重新开始

你不必记住所有命令。输入 `/` 之后，会自动显示可用的命令列表。

## 多行输入怎么办

有时候一句话说不完。按 `Alt+Enter`（Mac 上是 `Option+Enter`）就能换行，不会误发送。

## 想退出

按 `Ctrl+C`。如果 AI 正在回答你，第一次按会停止生成，再按一次才退出。
