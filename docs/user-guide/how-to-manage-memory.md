# 如何管理对话记忆

> 1. `/summary` 让 AI 存记忆
> 2. 多执行几次，积累多了让 AI 整理
> 3. 新开一个会话
> 4. 提示 AI 清理：删除重复、过时、不再相关的内容

## 记忆系统怎么工作

记忆帮你保存项目相关的知识，让 AI 更懂你的项目。

AI 知道有哪些记忆可用，只在相关时才会读取完整内容。记忆的元数据（名称、描述）会加载到系统提示词。

## /summary 用多了，AI 就懂你的项目

用 `/summary` 压缩对话，AI 会提取关键信息存到记忆里。

多执行几次，AI 积累的记忆就多了，自然更懂你的项目架构、编码规范、踩过的坑。

## 定期整理记忆

记忆需要保持及时和简略。

经常让 AI 整理：

```
整理一下项目记忆，删过时的，补缺的，保持简洁
```

这样记忆不会越堆越多，也不会有过时信息干扰。

## 记忆文件多了怎么办

新开一个会话，然后提示 AI 清理：

```
清理项目记忆，删除重复、过时、不再相关的内容，保持精简
```

新会话没有对话历史，AI 能更客观地评估记忆的有效性。

## 记忆什么时候存

主动触发时才存储：

- `/summary` - AI 分析当前对话，提取关键信息存记忆
- 或者你明确要求"把这个存到记忆"

AI 不会自动存，你控制什么时候存、存什么。
