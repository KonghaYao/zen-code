# 如何使用 MCP 工具

> 1. `/mcp` 打开面板
> 2. 添加/编辑/删除服务器
> 3. 从文档复制 JSON 配置粘贴
> 4. 保存配置
> 5. 检查状态栏确认连接状态

## MCP 是什么

MCP（Model Context Protocol）是一个协议，让 AI 能用额外的工具。

Zen
Code 自带基础工具：读文件、写文件、运行命令。但你可能还想让 AI 做些它默认做不到的事——访问数据库、调用外部 API、操作浏览器、读取特殊格式的文件。MCP 就是为此准备的。

## 你需要配置 MCP 吗

写写代码、改改文件的话，默认工具就够用了。

但如果你想让 AI 查数据库、调用你公司的内部 API、操作 GitHub、Jira 这类服务，那就得配 MCP 服务器。

## 配置方式

### 通过 TUI 配置（推荐）

输入 `/mcp` 打开 MCP 面板。

**添加服务器：**

1. 按 `n` 进入新增模式
2. 输入服务器名称（比如 `filesystem`）
3. 从 MCP 服务器文档复制 JSON 配置，粘贴到 Config 字段
4. 按 `Enter` 保存

**JSON 配置是什么**

JSON 配置是 MCP 服务器启动时需要的参数，通常长这样：

```json
{
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-filesystem", "/home/user/projects"]
}
```

每个 MCP 服务器的配置都不一样，你需要从对应 MCP 服务器文档里找到正确的配置。比如：

- GitHub MCP 服务器文档会告诉你用 `"command": "npx"` 和 `"args": ["-y", "@modelcontextprotocol/server-github"]`
- 需要认证的服务器文档还会要求你添加 `"env"` 字段，填 API Key 之类的

**重要：** 不要自己瞎写配置，从 MCP 服务器的官方文档复制。

**编辑服务器：**

1. 用 `↑` `↓` 选择服务器
2. 按 `e` 编辑配置
3. 修改后保存

**删除服务器：**

1. 选择要删除的服务器
2. 按 `d` 确认删除

## 查看 MCP 状态

### 在 TUI 里看

输入 `/mcp` 打开面板，能看到配置了哪些 MCP 服务器和它们提供的工具。

### 状态栏

底部状态栏会显示 MCP 连接状态：

- `● MCP` - 已连接（绿色）
- `○ MCP` - 未配置或连接失败（灰色）

## 配置验证

配置格式错了，TUI 会提示。检查 JSON 格式，或者从对应 MCP 服务器的文档重新复制配置。

## 禁用 MCP

`/mcp` 打开面板，选服务器按 `d` 删。
