# Codebase Flows

`.codebase/` 是项目的预生成知识库，记录了代码**如何运作**的端到端路径。

> **规则**：在对项目代码做任何搜索（grep、glob、读文件）之前，先查阅
> `.codebase/`。知识库能直接回答的，不需要再去搜索源码。

## .codebase 目录结构

```
.codebase/
├── FLOWS.md              # 所有流程的索引，从这里出发
└── FLOWS/
    ├── user-message.md   # 每个核心流程的详细调用链
    ├── agent-creation.md
    └── ...
```

## 如何使用 .codebase 回答问题

**第一步：先读 `FLOWS.md`**

`FLOWS.md` 是索引，列出所有已文档化的流程及其描述，先找到最相关的条目。

**第二步：读对应的流程文件**

每个 `.codebase/FLOWS/{id}.md` 包含：

- **调用链**：从入口到出口的完整路径，含文件名和函数名
- **关键节点表**：重要位置一览
- **开发者注意**：容易踩的坑和非显而易见的行为

**典型问题 → 查哪里**

| 问题                             | 做法                                           |
| -------------------------------- | ---------------------------------------------- |
| "用户消息怎么到达 LangGraph？"   | 读 FLOWS.md 找相关流程 → 读该流程文件的调用链  |
| "HITL 审批在哪里被触发？"        | 在调用链中找 `hitl` 相关节点                   |
| "配置修改后怎么同步到环境变量？" | 找 config/sync 相关流程                        |
| "某个中间件在哪个阶段执行？"     | 找 agent-creation 或类似流程，看 Middleware 层 |

## 知识库不存在或不完整时

如果 `.codebase/FLOWS.md` 不存在，或缺少你需要的流程，参考 [INIT.md](./INIT.md) 初始化或补充文档。
