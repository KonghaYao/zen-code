# Information Visualization and Charts Prompt Templates

## 4.1 Infographics

**Technique**: Clear hierarchy + visual balance + concise text

```
Create an infographic for [topic].

Content Structure:
- Main Title: [Large title, concise and powerful]
- Subtitle: [Subtitle or description]

Data/Information Blocks:
1. [Data point 1]: [Value] + [Icon/Graphic]
2. [Data point 2]: [Value] + [Icon/Graphic]
3. [Data point 3]: [Value] + [Icon/Graphic]
...

Visual Elements:
- Icons: [Icon style]
- Chart Type: [e.g., bar chart/pie chart/line chart]
- Color Coding: [Color scheme]

Design Style:
- Modern, flat design
- Clear visual hierarchy
- Rich cartoon characters and elements (optional)

Text Requirements:
- English (or Chinese)
- Concise, retain main information
- Readable font and size

Layout: [Layout description, e.g., vertical/horizontal/radial]
Background: [Background type and color]
```

**Example**: World's tallest buildings infographic, sweets ranking

## 4.2 Educational Comics

**Technique**: Unified style + step-by-step explanation + card layout

```
Create a series of educational comics for [topic/concept].

Topic: [Concept name]
Target Audience: [Age group]

Requirements:
- Generate multiple [ratio, e.g., 16:9] doodle-style images
- Unified colorful, bold hand-drawn style
- Information-rich
- Use English text
- Solid color background
- Outline around cards
- Unified titles

Content for each card:
1. Title: [Card 1 title]
   Content: [Card 1 main information]
   Visual elements: [Card 1 visual description]

2. Title: [Card 2 title]
   ...

Style: Doodle/Hand-drawn style
Color Palette: [Color scheme]
Overall appearance: Similar to PowerPoint presentation
```

**Example**: Comic strips explaining "futures" concepts to middle school students

## 4.3 Knowledge Reasoning Image Generation

**Technique**: List format + visualization + ranking

```
Generate a knowledge reasoning image for [topic].

Format: [Top N] ranking list

Content:
1. [Rank 1]: [Item name]
   - [Brief description]
   - [Visual elements]

2. [Rank 2]: [Item name]
   - [Brief description]
   - [Visual elements]

...

Design Requirements:
- Colorful infographic
- Clear ranking display
- Visual representation for each item
- Concise text descriptions

Style: [Style description, e.g., modern/cartoon/tech]
Layout: [Layout description, e.g., vertical list/circular arrangement]
```

**Example**: Top 5 tallest buildings ranking, sweetest foods on Earth

## 4.4 Relationship Diagrams/Flowcharts

**Technique**: Nodes + connections + clear labels + layout

```
Create a relationship diagram/flowchart for [topic].

Nodes (Entities):
- Node 1: [Entity name]
  - Icon/Image: [Visual representation]
  - Attributes: [Attribute list]
- Node 2: [Entity name]
  - ...

Connections (Relationships):
- Node A → Node B: [Relationship type]
  - Line type: [Solid line/Dashed line/Arrow]
  - Label: [Relationship description]
- Node B ← Node C: [Relationship type]
  - ...

Layout:
- Node arrangement: [Layout method, e.g., circular/hierarchical/free]
- Connection routing: [Clear, avoid crossing confusion]

Labels:
- Node labels: [Entity name and key attributes]
- Relationship labels: [Relationship type and description]

Style: [Style description]
Colors: [Color coding scheme]
Background: [Background type]
```

**Example**: Game character relationship diagram, character affection chart
