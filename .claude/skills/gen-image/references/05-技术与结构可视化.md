# Technical and Structure Visualization Prompt Templates

## 5.1 Exploded View Diagram

**Technique**: Layered separation + connection lines + annotations + transparent shell

```
Create an exploded view display diagram of [object/toy].

Subject: [object name]

Explosion structure:
Left side (complete appearance):
- Complete appearance of [object]
- Normal toy image

Right side (internal structure):
- Semi-transparent shell, clearly displaying internal structure
- Use white lines to mark name and position of each part
- Parts separated to display assembly relationship

Annotation system:
- Connection lines extend from each part to annotations
- Annotation content: [part name + brief function]

Desktop background:
- Bright background
- Blurred desktop effect
- Focus on subject

Overall display:
- Left side shows complete appearance
- Right side shows detailed explosion with annotations and parameters

Style: Technical diagram, clear annotations, professional style
```

**Example**: Toy exploded view diagram, electronic product internal structure

## 5.2 Material Ball/Material Showcase

**Technique**: Pure material display + lighting variation + multiple angles

```
Display material ball of [material type].

Subject:
- Material type: [such as glass/metal/wood/plastic]
- Shape: sphere or multiple geometric shapes
- Size: [size description]

Lighting and reflection:
- Multiple angle lighting
- Reflection visible
- Refraction effect (if applicable)
- Highlight and shadow contrast

Material features:
- Color: [main color tone]
- Roughness: [smooth/rough degree]
- Transparency: [transparent/opaque]
- Texture: [texture description]

Background:
- Solid color background
- Gradient background
- Or environment reflection

Render quality:
- Ultra high quality
- Rich lighting details
- 3D render style, such as C4D/Blender

Usage: Material reference that can be applied to other objects
```

**Example**: Crystal material ball, metal material ball, wood material ball

## 5.3 Holographic Projection

**Technique**: Volumetric light + projection source + illusory feel

```
Create a holographic projection display of [character/object].

Subject:
- Projection object: [character/object name]
- Projection state: floating/standing/action

Projection source:
- Type: Circular holographic projector
- Size: Ø120mm
- Position: Placed on modern desktop

Projection effect:
- Volumetric light: defined solely by volumetric light
- Semi-transparent effect: 0.3-0.5 opacity
- Glowing effect: self-illuminating surface
- No solid surface: composed only of light and shadow
- Detail hierarchy: clear core, fading edges

Scene:
- Desktop: soft lighting
- Holographic figure: defined by volumetric light
- Background: seamless black studio, faint reflection

Photography setup:
- Angle: Front eye-level
- Aperture: f/11–f/16
- ISO: 100
- Use tripod

Output specs:
- Aspect ratio: 4:5
- Resolution: 2048×2560

Negative constraints:
- No text/watermarks/logos
- No brand images
- No resin/PVC solid statues
- Opaque surfaces
- Toy sheen
- Light beams/scan lines/dot patterns/distortion/excessive digital elements
```

**Example**: Character holographic projection, product holographic display

Color:

Background:
- Transparent background

Style: [style description, such as technical drawing/blueprint/modern line art]
