# Practical & Functional Image Prompt Templates

## 9.1 ID Photo

**Technique**: Standard size + Background specification + Pose requirements

```
Crop uploaded portrait to standard ID photo.

Crop Requirements:
- Head: Crop head, keep shoulders
- Size: 2-inch ID photo
- Ratio: Standard ID photo ratio (usually 35mm x 45mm)

Background:
- Color: [e.g., blue/white/red]
- Purity: Solid color background
- No shadow: No background shadow

Attire:
- Clothing: Professional business formal
- Color: [Dark/light, based on background selection]

Pose:
- Angle: Frontal, eye-level
- Eyes: Look directly at camera
- Expression: Slight smile, natural expression

Other Requirements:
- Hairstyle: Neat, not covering face
- Makeup: Natural, not excessive
- Glasses: Can be worn, but no reflection

Style:
- Standard, professional
- Meets ID photo specifications
- Suitable for various documents
```

**Example**: Passport ID photo, ID card photo, visa photo

## 9.4 Emoji/Sticker

**Technique**: Simple outline + Emotion expression + White border

```
Create emoji/sticker series based on [character/theme].

Emoji Type:
- White outline sticker
- Web illustration style
- Simple and cute

Emoji List (at least include):
1. Happy/Laughing
2. Angry/Raging
3. Sad/Crying
4. Surprised/Shocked
5. Thinking/Confused
6. Heart/Like
7. Helpless/Sigh
8. Terrified/Scared

Design Style:
- Shape: Simplified, exaggerated character design
- Lines: White outline (if applicable)
- Colors: [Color scheme]
- Background: [Transparent/white/colored]

Text (optional):
- Phrase: Short descriptive phrases
- Position: [Above/below/beside sticker]
- Font: [Font style]

Consistency:
- All emojis maintain consistent style
- Character features recognizable
- Clear emotion expression

Output:
- Multiple independent emoji images
- Suitable for chat emoji use

Style:
- Cute, simple
- Suitable for social media use
```

**Example**: Character emoji, themed sticker series, LINE stickers
