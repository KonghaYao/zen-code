- Spatial reasoning: Deduce 3D structure based on original viewpoint
- Viewpoint conversion: Convert to target viewpoint
- Detail preservation: Preserve main elements and details

Position Marking:
- Photographer position: Mark photographer position of original photo
- Marking method: [Icon/arrow/color highlight]

Content Preservation:
- Subject: Maintain main subject
- Environment: Maintain main features of environment
- Proportion: Adjust proportion to fit new viewpoint

Style:
- Maintain original image style
- Realistic/artistic style consistent

## 10.3 Reference Image Facial/Expression Control

**Technique**: Facial feature extraction + Expression application + Identity preservation

```
Use reference image to control target image's facial expression.

Reference Images:
- Image 1 (target): [Person image, maintain identity]
- Image 2 (reference): [Facial/expression reference]

Control Targets:
- Face shape: Apply facial shape features from image 2
- Expression: Apply expression from image 2
- Identity: Maintain identity features from image 1

Preserved Elements:
- Overall appearance: Maintain overall appearance from image 1
- Body: Maintain body pose and position
- Clothing: Maintain clothing
- Background: Maintain background

Applied Elements:
- Facial contour: Reference facial contour from image 2
- Expression details: Apply expression details from image 2
- Features: Apply facial features from image 2

Style:
- Maintain image style consistency
- Natural blending
- No visible splicing traces

Output:
- Single image
- Fused best features from both images
```

**Example**: Reference image control facial expression, expression transfer, facial feature blending
