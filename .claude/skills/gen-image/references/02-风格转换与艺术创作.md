# Style Transfer and Art Creation Prompt Templates

## 2.1 Ukiyo-e Style

**Technique**: Specific artistic features + material requirements + color scheme

```
A [theme] Ukiyo-e style collector's trading card design, vertical composition.

Must mimic the visual aesthetics of "Demon Slayer", featuring:
- Varying thickness ink outlines
- Traditional handmade paper texture
- Flat color areas, no gradients
- Japanese patterns and motifs
- Dynamic poses and composition

Central character: [character description], [action/pose]
Background: [background elements, such as cherry blossoms, mountains, waves]

Card edge: [decorative elements]
Border design: [specific border style]

Material: Handmade paper texture, slight vintage effect
```

**Example**: Ukiyo-e style character card, mimicking Demon Slayer art style

## 2.2 Scribble/Doodle Style

**Technique**: Hand-drawn texture + thick outlines + solid background

```
Convert the uploaded image to a doodle painting style, like an illustration in a picture book.

Style requirements:
- Rough hand-drawn lines
- Imperfect contours and shapes
- Solid color background (not gradients)
- Visible brushstrokes and textures
- Child-like simple style
- Cartoonized elements

Content: Keep the original image's [subject and scene]
Colors: Use [color scheme, such as soft/vibrant/monochrome]
Composition: Keep the original image's [composition/layout]
```

**Example**: Convert photo to children's picture book doodle style

## 2.3 Crystal/Glass Material

**Technique**: Transparency + refraction + light & shadow + beveled edges

```
Create a hyper-realistic, highly detailed image showing [object] rendered as transparent, high-polish glass or crystal material.

Object features:
- Subject has clear thickness and 3D depth
- [object's iconic shape and features]
- Simplified but extremely precise geometric structure, making it easily recognizable

Material details:
- All edges are rounded and beveled
- Smooth curved surfaces creating elegant refraction effects under light
- Transparent/translucent, showing internal structure

Lighting and rendering:
- Slightly tilted, as if floating above [background type]
- High-key lighting, shallow depth of field
- Subject is absolutely sharp and clear
- Background is softly blurred to maximize subject emphasis

Style: 3D render, C4D style, minimalist background
```

**Example**: Crystal Polaroid camera, glass material logo

## 2.4 Inflatable/Plush Toy

```
Create a high-resolution 3D render converting [object] into an inflatable plush toy.

Shape features:
- Soft and plump, like a plush balloon or inflatable toy
- Rounded edges, no sharp angles
- Inflated feel, full of air

Material texture:
- Smooth matte texture
- Add subtle fabric texture
- Slightly visible stitching (optional)
- Soft shadows and highlights

Lighting:
- Bright, even lighting
- Soft shadows
- Slight ambient occlusion

Background: [background type, such as pure white/colored gradient]
```

**Example**: Inflatable plush toy logo, plush character figurine

## 2.6 Isometric/Isometric View

**Technique**: 45-degree angle + top-down + unified perspective + structured

```
Convert the uploaded image/map to isometric view.

View requirements:
- 45-degree top-down angle
- Isometric perspective (no perspective distortion)
- All vertical lines remain vertical
- All horizontal lines at unified angle (30 or 45 degrees)

Structure requirements:
- Convert flat elements to 3D blocks
- Buildings show front and side faces
- Unified height and proportions

Style: [art style, such as pixel art/3D render/hand-drawn]
Details: Maintain [original elements' details]
Colors: Use [color scheme]

Background: [background type, such as transparent/solid color/gradient]
```

**Example**: Map to isometric buildings, 3D scene isometric view
