# Character & Portrait Prompt Templates

## 1.1 Character Cloning / Multi-Character Scene

**Technique**: Layered description + Position distribution + State definition

```
Based on uploaded character reference, generate [scene type] scene:

Foreground (character focus zone):
- [number] characters, [specific actions and positions]
- Each character's [pose/expression/interaction]

Midground (main area):
- [number] characters, [specific activities]
- Spatial relationships and [interaction methods]

Background (depth space):
- [number] characters, [positions and actions]
- Environment [detail elements]

Maintain [character name] identity consistency, [style requirements]
```

**Example**: Clone characters into Tokyo girls' apartment scene, layered description of 20 different poses

```

• Clothing layers—show [specific number of layers and materials]
```
