# Product and Commercial Design Prompt Templates

## 3.1 Product Packaging Design

**Technique**: Brand Integration + Information Hierarchy + 3D Display

```
Design professional packaging for [product].

Packaging Box Structure:
- Shape: [Box type, such as hexahedron/cylindrical/special shape]
- Size ratio: [Specific ratio or dimensions]
- Opening method: [Opening type]

Design Elements:
Front:
- Main logo/brand identity
- Product name: [Product name]
- Main selling points: [List of selling points]
- Product image: [Product display method]

Sides:
- Product information: [Detailed list]
- Usage instructions: [Brief instructions]
- Barcode area

Back:
- Detailed description
- Ingredients/specifications
- Warnings/precautions

Top/Bottom:
- Seal/opening indicator
- Recycling symbol

Visual Style:
- Color scheme: [Primary/secondary colors]
- Font: [Font style]
- Graphic elements: [Decorative elements]
- Texture: [Packaging material, such as glossy/matte/textured]

3D Rendering:
- Isometric or perspective view
- Product visible inside box (transparent window or open display)
- Accessory display
- Photorealistic rendering style, high-quality lighting
```

**Example**: Character toy packaging box, skincare packaging design

## 3.2 Miniature Scene/Diorama

**Technique**: Scale Contrast + Fine Details + Environment

```
Create a [theme] miniature scene.

Scene Description:
- Theme: [Scene theme]
- Scale: e.g., 1:100 scale
- Scene type: [e.g., street, room, landscape]

Main Elements:
- Center subject: [Miniature subject]
- Surrounding environment: [List of environmental elements]
- Props: [List of detail items]

Detail Requirements:
- Ultra-fine textures and details
- Realistic scale proportions
- Tiny everyday objects

Environment:
- Ground: [Ground material]
- Background: [Background scene]
- Lighting: [Lighting type]

Material Effects:
- Handmade polymer clay texture (optional)
- Microscopic texture visible
- Small size but ultra-detailed and brand-accurate

Photography Style:
- Macro photography
- Shallow depth of field
- Soft shadows
- Professional product photography atmosphere

Background: [Background type, e.g., pure white/gradient/scene]
```

**Example**: Miniature store, theme park miniature model, miniature home scene

- Background: [Background description]

Atmosphere:
- Mood: [Mood description]

## 3.4 Physical Merchandise Design

**Technique**: Diverse Formats + Unified IP + Commercial Presentation

```
Design a series of physical merchandise based on [character/brand].

Merchandise Types (at least include the following):
1. Figurine: [Size, pose, style]
2. Plush toy: [Style, texture, expression]
3. Acrylic standee: [Size, design, pose]
4. Keychain/Badge: [Shape, design, material]
5. T-shirt/Clothing: [Pattern, position, style]
6. Poster/Postcard: [Size, theme, style]
7. Notebook/Stationery: [Type, design elements]

Display Layout:
- Merchandise neatly arranged on [display shelf/table/wall]
- Maintain [overall atmosphere, such as cute/trendy/professional]
- Multiple angles showing different products

Design Principles:
- Unified IP recognition
- Diverse presentation forms
- Suitable for commercial production and sales

Style: [Style description, e.g., dreamy/pop/professional]
Quality: 4K, ultra-realistic details
```

**Example**: Character merchandise shelf, anime merchandise display stand
